# Deployment

The existing Render Blueprint retains its unique service names. The static service serves `/` as the landing page and rewrites all paths to `index.html`; `/command-centre` and workspace routes therefore survive refresh. Immutable caching applies to hashed assets.

The API uses `/api/v1/health` for lightweight health checks. `ROLE_TOKEN_SECRET` is generated by Render. Trial codes remain server-side environment variables. The API installs production dependencies only.

Deployment commands:

```powershell
git push origin main
# Render Dashboard → Blueprint → Apply, or Manual Deploy → Deploy latest commit
```

SQLite at `/tmp` is ephemeral on Render free services. Use managed PostgreSQL and enterprise identity for durable production use. Free services may cold-start slowly.
